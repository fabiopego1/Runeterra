Pictures for the region galleries of the Lore page (Grupos, Ambientes, Criaturas): official Riot art from
Legends of Runeterra (Data Dragon) and the League of Legends Universe galleries, 480px wide.

Generated by `tools/lore-gallery/build.py`, which also writes `js/pt/lore-gallery.js`. Don't edit these
files by hand: change the groups in `tools/lore-gallery/groups.py` and run the script again. It leaves out
any art already used elsewhere on the site.
